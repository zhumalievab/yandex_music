# Задание 5. Инструменты для функционального тестирования

1. **Adroid Studio**: для запуска приложения на эмуляторе или реальном устройстве, проверки работы функции установки фотографии и просмотра логов для поиска ошибок
2. **Любое устройство Android**: для проверки установки фотографии в условиях реального использования, включая работу галереи и особенностей разных версий Android.
3. **Charles Proxy**: для перехвата и анализа запросов и ответов сервера при загрузке фотографии, а также проверки обработки ошибок сети
