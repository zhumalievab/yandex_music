# Задание 4. Техники тест-дизайна, которые были использованы в моих заданиях

### 1. Эквивалентное разделение

разделение проверяемых данных на группы, у которых ожидается одинаковое поведение или результат. для теста выбирается несколько значений из каждой группы. у меня это размер и формат фото

### 2. Анализ граничных значений

проверка значений на границах допустимого диапазона, где чаще всего возникают ошибки. у меня это по размеру в 5 МБ

### 3. Предугадывание ошибок

поиск возможных ошибок на основе опыта и предположений тестировщика о том, в каких ситуациях система может работать некорректно. по сути тут частично только упоминание всплывающего окна об ошибке, но все же оно у меня есть :р но могу ошибаться (

### 4. Тестирование состояний и переходов

проверка состояний функций и переходов между ними в зависимости от действий пользователя
