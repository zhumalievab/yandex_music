# Тестовое задание для вакансии "Инженер по мобильному тестированию (стажёр) в Музыку"
## Описание задания:

В некоторой социальной сети можно установить аватар для профиля. Чтобы поставить фото профиля, нужно загрузить изображение с устройства. Ваша задача — протестировать, как работает загрузка картинки и установка фото профиля в нативном мобильном приложении на Android. При этом изображение должно соответствовать таким требованиям:

> Формат файла — JPEG или PNG.
Размер файла не должен быть больше 5 МБ.
На аватаре должно быть чётко видно лицо человека.
Аватар должен быть реальной фотографией, а не изображением, сгенерированным с помощью ИИ.

Выполните следующие задания:
> Задание 1. Определите, какие сценарии нужно учесть при тестировании.
<br> Задание 2. Составьте чек-лист проверок, которые нужно выполнить, чтобы протестировать установку фото профиля.
<br> Задание 3. На основе чек-листа разработайте тест-кейсы — они должны покрывать все проверки из чек-листа.
<br> Задание 4. Опишите техники тест-дизайна, которые вы использовали, когда составляли чек-лист и тест-кейсы.
<br> Задание 5. Перечислите инструменты, которые стоит использовать для проверки функциональности.

Решение каждого задания будет в папке tasks
